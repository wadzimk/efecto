📋 Как добавить сорт в efecto.html

  1. Открой efecto.html в любом текстовом редакторе (TextEdit на Mac, VS Code, Notepad)
  2. Нажми Cmd+F (Mac) или Ctrl+F (Windows) и найди: // ← PASTE NEW STRAINS HERE
  3. Поставь курсор перед этим комментарием
  4. Вставь скопированный код — он уже содержит запятую в начале
  5. Сохрани файл. Готово!

🗺️ Новый город на карте?

  1. Найди в файле: // ← PASTE NEW CITIES HERE
  2. Добавь строку вида: { name: "Prague", lat: 50.08, lng: 14.44 },
  3. Координаты (lat/lng) легко найти в Google Maps — правый клик на город → "Что здесь?"

✅ Сорт появится автоматически во вкладке Strains, в Effects и на карте если город уже есть!
